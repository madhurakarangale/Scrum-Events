# ScrumFlow Pro 🚀

Enterprise-grade Agile Project Management Tool

## Features

- 🔐 **User Authentication** - Secure login and registration
- 📝 **Story Management** - Create, edit, and delete user stories
- 📊 **Task Board** - Visual workflow with To Do, In Progress, Done columns
- ⚡ **Velocity Tracking** - Automatic team velocity calculation
- 📋 **Activity Log** - Complete audit trail of all actions
- 💾 **Cloud Sync** - All data stored in PostgreSQL database
- 📦 **Import/Export** - JSON backup and migration
- 🔄 **Real-time Updates** - Changes saved instantly
- 📱 **Responsive Design** - Works on all devices

## Tech Stack

### Frontend
- HTML5, CSS3, JavaScript (Vanilla)
- Font Awesome Icons
- Google Fonts

### Backend
- Node.js + Express
- PostgreSQL Database
- JWT Authentication
- Bcrypt Password Hashing

### Deployment
- Vercel (Frontend + Backend)
- PostgreSQL (Supabase or any PostgreSQL provider)
